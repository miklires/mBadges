# mBadges

Graphical player badges for Paper and Purpur servers.

Development for the first stable release is in progress.

## Requirements

- Java 25
- Paper or Purpur 26.2

## Build

```bash
./gradlew clean build
```

The server plugin is written to `build/libs/mBadges-1.0.0.jar`. The public API is written to `api/build/libs/mBadges-API-1.0.0.jar`.
